# scoop-motrix-next

Scoop bucket for [Motrix Next](https://github.com/AnInsomniacy/motrix-next) — a full-featured download manager, rebuilt from the ground up.

## How to add this bucket

```powershell
scoop bucket add motrix-next https://github.com/gandli/scoop-motrix-next
```

## How to install

```powershell
scoop install motrix-next
```

## How to update

```powershell
scoop update motrix-next
```
